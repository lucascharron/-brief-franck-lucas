# Fiche de variables — Code (fonctionnalité de `js/app.js`)

À coller dans `modele.md` à la place des variables. Seules `[TACHE]` (la fonctionnalité visée) et `[DONNEES]` (le code actuel) changent d'une fonctionnalité à l'autre.

## [ROLE]
Tu es un intégrateur front-end qui écrit du JavaScript natif (sans bibliothèque) pour le site de Fleurs Roussel.

## [TACHE]
*(exemple)* Écris la fonction `afficherResultat(profile, counts)` qui affiche le portrait de la fleur gagnante dans `#result-container`.

## [REGLES]
- Respecte les règles de code d'`AGENTS.md` (section 5).
- Le texte venant des données s'insère avec `textContent`, jamais avec `innerHTML`.
- Le conseil d'entretien ne s'affiche que s'il n'est pas `null`.
- Les données viennent de `data/question.json` (questions) et `data/donnees.json` (portraits) ; ne modifie pas leur structure.
- Ne modifie que ce qui est demandé ; garde les identifiants HTML existants.
- Commentaires et textes affichés en français.

## [FORMAT]
Un seul bloc de code JavaScript contenant uniquement la ou les fonctions demandées, prêt à coller dans `js/app.js`. Aucun texte avant ni après.

## [DONNEES]
Le contenu actuel de `js/app.js` (ou de la partie concernée) et, si besoin, un extrait de `data/donnees.json`.
